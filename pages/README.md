# Pages Directory

This directory houses all secondary and multi-page application views for Whizcamp.

### Page Architecture:
- Every subpage links to:
  - `../assets/css/globals.css` (Universal resets and typography)
  - `../assets/css/pages/page.css` (Common layout, navigation, and footer styles)
  - `../assets/js/main.js` (Universal event handling and interactive scripts)
  - Local assets via `../assets/icons/` and `../assets/images/`
  - Back to the main homepage via `../index.html`

### Available Pages:
- `services.html` - Capabilities and tech service offerings
- `about.html` - Company mission, vision, and core differentiators
- `contact.html` - Consultation booking and inquiry form
- `blog.html` - Engineering perspectives, tech insights, and articles
